## 1. 交付结果

新增第一方“轻量冒险规则包”，可从 `/plugins` 或娱乐模式进入。它包含“雾港来信”和“星灯遗迹”两个世界模板，支持主角名称、专长、叙事氛围与内容边界配置；采用三属性、10 点生命和轻量 d20 规则。

用户先保存配置并查看完整设定，再点击确认创建独立 GameSession。配置改变会撤下旧预览，确认按钮防止重复点击创建；进入游戏会打开明确指定的 Session，避免被另一设备新建的会话抢占。正式故事沿用已有剧情树、骰子/检定、分支状态、检查点和导出。

新增包仅使用 Plugin API 1.0.0 已有的隔离存储，不增加 npm 依赖、能力 ID 或数据库迁移。新增规则包通过模块、Manifest/Activity/规则 Registry 和专属 UI 接入；本轮没有修改 Agent/GameTurn 循环、GameSession Repository、数据库 Schema/迁移或冻结的 `pluginApiV1.ts`。

## 4. 用户操作与真机验收

1. 打开 `/plugins`，启用“轻量冒险规则包”，授权“插件隔离存储”。此次部署没有代替用户启用或授权。
2. 进入“打开轻量冒险”，选择模板并保存/预览；检查角色数值和内容边界。
3. 点击“确认创建游戏会话”，进入游戏，再点击“开始故事”，输入行动或台词。
4. 如故事需要检定，按建议在宿主 UI 选择角色、属性与难度，确认可信结果和后续状态。
5. 在最新 APK 上检查配置与网页一致、两个模板均可用，以及进入正确会话。继续使用既有华为通知真机清单。
