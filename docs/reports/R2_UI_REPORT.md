# R2：全模式 UI 与导航优化交付报告

日期：2026-10-02。范围：现有 Web / Capacitor 本地 React Client 的导航、共享视觉与交互；不改 Agent Loop、模型调用、数据库、Plugin API 或通知投递机制。

结论：R2.1/R2.2 实现以及 R2.3 自动验证已交付；华为真机与用户视觉确认仍保留，不宣称整体验收封版。用户此次指令优先于原 R1→R2 顺序，R1 真实费用/质量对照及长聊天摘要仍未完成。

## 1. 已完成的改动

| 范围 | 本轮交付 |
|---|---|
| 导航 | 统一分组 Registry 与 AppShell，18 个主要页面共用；桌面侧栏，手机抽屉，不增加占用输入空间的常驻底栏 |
| 模式入口 | 专业/陪伴/反思先提出切换意图并确认；学习/娱乐是独立页面，打开不启用插件、不调用模型、不创建任务/游戏 |
| 学习 | 新增 `/study` 活动入口，保留背书/解题的原有权限、插件启用与业务流程 |
| 聊天 | 独立历史抽屉、多行输入、输入法 Enter 保护、回答阅读宽度、公式/代码/表格内部滚动、来源折叠；分支和规则警告保留 |
| 任务与设置 | 共用标题、间距、卡片、按钮/表单、选中态及焦点样式；时间滚轮复用原生弹层，循环时间逻辑不变 |
| 学习/游戏 | 活动和表单离开确认；游戏剧情优先，世界/角色与检查点可展开，折叠不卸载子组件 |
| 草稿 | 与已保存基线比较，取消离开保留输入；保存成功解除提示；聊天按会话内存隔离，返回恢复最后会话 ID |
| 弹层/无障碍 | 原生 dialog、背景 inert、Tab 循环、Escape/遮罩关闭、焦点恢复与跳至主要内容；主要控件约 44px |
| 本地 APK | 补齐首页/学习路由、同页 hash 模式意图和草稿保护；Android 返回先关闭弹层；连接提示改为占位状态条 |

18 个页面：首页、聊天、学习入口、背书、解题、娱乐、轻量冒险、任务、Inbox、阅读、思考问题、记忆、人格、主动联系、语音、通知、API 配置与插件。

本轮是共享布局和关键交互优化，不是重新设计每一个业务表单。原有长表单字段、模型专业性/人格、错误/权限/冲突反馈、数据隔离与默认开关仍保留；后续可根据实际视觉反馈继续迭代。

## 5. 保留项与后续

- R2 真机、软键盘、Android 返回和视觉偏好验收待用户反馈；不把 Web/本地 Bundle 结果当作 HarmonyOS 系统结果。

- R1 的真实费用收益、摘要正确性与净成本验收继续保留；本轮未承诺缓存命中率或节省比例。

- Huawei Push、定制音色、完整桌游规则/第三方市场不是 R2 内容。后续遵循主线指导进行移动/语音验收、Phase 5.6 与作品集交付。
