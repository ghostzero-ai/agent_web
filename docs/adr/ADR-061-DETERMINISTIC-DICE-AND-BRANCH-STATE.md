# ADR-061：确定性骰子与分支状态快照

状态：已接受（Phase 6.3）

## 背景

Phase 6.2 已有可分支剧情树，但回合只有自由文本。让模型自行声称骰子结果无法审计或复现；只保存一个 Session 级“当前状态”又会让历史分支错误继承其他分支的物品和场景。

## 决策

1. 骰子只由服务端 Dice Tool 执行，算法固定为带版本号的 `fnv1a-mulberry32-v1`。不可变事件保存请求、seed、逐骰结果、总和与算法版本。
2. 模型每回合只可返回严格 JSON：`narrative` 与 `statePatch`。未知字段视为越权输出并拒绝。
3. 每个 `game_turn` 同时保存补丁和应用后的完整快照。新分支从父回合快照继续；根分支从世界设定构造初始状态。
4. 状态应用拒绝非法键、非有限数值、越界值以及调整后为负的资源或物品数量。
5. 回合、快照、Dice 事件和活动叶子在同一事务写入；模型输出或状态应用失败时不创建任何持久记录。

## 结果

- 任意骰子事件均可独立复算，模型不能伪造可信点数。
- 分支既隔离叙事上下文，也隔离结构化状态。
- 完整快照会增加 JSONB 存储，但当前个人项目规模很小，并显著简化分支读取、导出和 Phase 6.4 检查点实现。
- 本阶段状态仍是通用最小模型；人物属性、规则检定、结构化道具和检查点留给 Phase 6.4，规则包留给 Phase 6.5。
