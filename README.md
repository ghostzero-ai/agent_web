# AI Study Companion

## 项目简介

这是一个支持用户自定义API Key的AI Agent网站。

目标不是快速堆功能，而是完成一个长期维护、结构清晰的软件工程项目。

主要方向：

* 情感陪伴
* 学习辅导
* Prompt实践
* AI Agent开发

---
